# Tasks

All source paths are under `packages/client/`. Commands run from `packages/client/` unless they start with `pnpm --filter` or `git`, which run from the repository root. Prerequisite: `add-zone-rules-from-iana` is implemented (its reader, wrapper, `loadZoneRules`, asset plugin, compiler and check).

- **Running tests:** one command at a time, never in the background. Mutation runs take at most 5 files per run.
- **Time in tests:** `fakeClock` / `createSwitchableClock`; page visibility through `setPageVisibility`; online state injected, never `navigator.onLine` directly in tests.
- **Traceability:** every new artifact names `add-remote-zone-rules-updates` with its id (tags, `// @…` comments, JSDoc `Implements FR-X of add-remote-zone-rules-updates`).
- **File size:** every new or changed file stays under 200 lines (`app_shell_notices.steps.ts` is 273 and stays untouched; new notice tests go into new files); verify with `wc -l`.
- **Design references:** "design Dn" refers to `design.md`.
