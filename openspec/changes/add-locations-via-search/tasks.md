# Tasks

All source paths are under `packages/client/src/`; commands run from `packages/client/` unless they start with `pnpm --filter`. Run tests one command at a time. Mutation runs: at most 5 files per run, e.g. `npx stryker run --mutate 'src/model/locations.ts'`, report in `reports/mutation/mutation-report.json`. Every new test, step file and feature carries `add-locations-via-search` traceability (`@add-locations-via-search @FR-X` tags, `// @add-locations-via-search @FR-X` before `f.Scenario`, `// Verifies NFR-X of add-locations-via-search` in E2E steps).
