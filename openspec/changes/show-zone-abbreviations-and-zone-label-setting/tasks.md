## 1. Glossary and architecture docs (FR1–FR16; FR7 for the wall-time hint)

- [x] 1.1 Update the glossary in the same change (`.claude/rules/glossary.md`), using the entry format of `docs/glossary/README.md`:
  - `docs/glossary/time.md`: new **Zone abbreviation** — the letter abbreviation from the IANA time zone database that a zone uses at an instant (`EST`, `EDT`, `IST`, `MSK`); a numeric tzdb designation (`+05`) is none. *RU:* сокращение пояса (interface: «Сокращение»). *Code:* `getZoneAbbreviation`, `formatZoneAbbreviation`, `virtual:zone-abbreviations`. *Not:* an `Intl` short zone name (`GMT+5`), a time zone ID. *Never:* zone code, TZ code, short name. New **Abbreviation pair** — the zone abbreviations a zone uses in a year, in order of increasing UTC offset (`EST / EDT`, `GMT / IST`); one for a zone with one offset. *Code:* `getZoneAbbreviations`.
  - `docs/glossary/locations.md`: new **Zone line** — the line of a location row under the city: the country name (on the device time location "Device time"), then the zone abbreviation and the UTC offset as the zone label allows, each a separate element. *RU:* строка пояса. *Code:* `presentZoneLine`, `ZoneLinePart`, `ZoneLinePartKind`, `LocationRow.zoneLineParts`. *Never:* subtitle. **Location row** lists the zone line and the zone abbreviation.
  - `docs/glossary/settings.md`: new **Zone label** — the preference that decides which zone parts the zone line shows, the UTC offset and the zone abbreviation, each on or off, both on by default; it does not affect the search. *RU:* «Подпись пояса»: «Смещение UTC», «Сокращение». *Code:* `Preferences.zoneLabelParts`, `ZoneLabelPart`, `SET_ZONE_LABEL_PART`, `useZoneLabelParts`, `ZoneLabelGroup`, `settings.zoneLabelLabel`. New **Toggle group** — a compact settings group in one row: a caption and independent toggle buttons, each on or off. *RU:* группа переключателей. *Code:* `SettingsToggleGroup`. **Settings page** and **Preferences** add the zone label.
  - `docs/glossary/search.md` **Abbreviation source**: "maps every zone abbreviation of the zone abbreviation table to the zones whose abbreviation pair contains it; an ambiguous abbreviation returns every match". *Code:* `createAbbreviationSource`, `getZoneAbbreviations` (replaces `timeZoneAbbreviations`).
  - `docs/glossary/date-selection.md` **Wall-time hint**: the overlap example becomes «01:30 бывает дважды — показано первое (EDT, UTC−4)», and the entry adds "the overlap hint always names the UTC offset of the shown instant and, when the zone label shows the zone abbreviation and the zone has one, names the zone abbreviation before it" (FR7). *Code:* stays `presentWallTimeHint`, which now also reads `zoneAbbreviationLabel` and `isZoneAbbreviationShown` (`WallTimeHintContext`).
  - `docs/architecture/domain-model.md`: add `ZoneLabelPart[] zoneLabelParts` to the `Preferences` class and `SET_ZONE_LABEL_PART` to the preferences commands.

  Verify from the repository root: `grep -n "Zone abbreviation\|Abbreviation pair" docs/glossary/time.md`, `grep -n "Zone line" docs/glossary/locations.md`, `grep -n "Zone label\|Toggle group" docs/glossary/settings.md`, `grep -n "getZoneAbbreviations" docs/glossary/search.md`, `grep -n "(EDT, UTC−4)" docs/glossary/date-selection.md`, `grep -n "isZoneAbbreviationShown" docs/glossary/date-selection.md` and `grep -n "zoneLabelParts" docs/architecture/domain-model.md` each print a line; `grep -n "timeZoneAbbreviations" docs/glossary/search.md` prints nothing; `wc -l docs/glossary/*.md` shows every file under 200 lines.
