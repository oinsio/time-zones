# Tasks

All source paths are under `packages/client/src/`; commands run from `packages/client/` unless they start with `pnpm --filter`. Run tests one command at a time, never in the background. Mutation runs: at most 5 files per run, report in `reports/mutation/mutation-report.json`. Time in tests comes only from `fakeClock(instant, timeZone)` of `@/lib/temporal` or a switchable `Clock` built on it — never `vi.setSystemTime()` or `vi.useFakeTimers()`; ticks come only from `createManualTickScheduler()` (`test/tickSchedulers.ts`), writes are observed with `createManualWriteScheduler()` (`test/writeSchedulers.ts`). Every new test, step file and feature carries `select-date-with-calendar-and-now` traceability (`@select-date-with-calendar-and-now @FR-X` tags above scenarios, `// @select-date-with-calendar-and-now @FR-X` before `f.Scenario`, `// Verifies NFR-X of select-date-with-calendar-and-now` in E2E steps, `Implements FR-X of select-date-with-calendar-and-now` in the JSDoc of new or changed production code). Keep every file under 200 lines.
