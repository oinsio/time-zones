# Tasks

All source paths are under `packages/client/src/`; commands run from `packages/client/` unless they start with `pnpm --filter`. Run tests one command at a time, never in the background. Mutation runs: at most 5 files per run, report in `reports/mutation/mutation-report.json`. Time in tests comes only from `fakeClock(instant, timeZone)` of `@/lib/temporal` or a switchable `Clock` built on it — never `vi.setSystemTime()` or `vi.useFakeTimers()`; timers come only from the injected tick scheduler (design D6). Every new test, step file and feature carries `show-local-time-and-date-on-location-cards` traceability (`@show-local-time-and-date-on-location-cards @FR-X` tags above scenarios, `// @show-local-time-and-date-on-location-cards @FR-X` before `f.Scenario`, `// Verifies NFR-X of show-local-time-and-date-on-location-cards` in E2E steps, `Implements FR-X of show-local-time-and-date-on-location-cards` in the JSDoc of new or changed production code). Keep every file under 200 lines.
