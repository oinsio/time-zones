# Tasks

All source paths are under `packages/client/src/`. Commands run from `packages/client/` unless they start with `pnpm --filter`, `git` or say "from the repository root". "design Dn" refers to `design.md`.

- **Running tests:** one command at a time, never in the background. Stryker runs only with `--mutate`, at most 5 files per run, and its report is `reports/mutation/mutation-report.json`.
- **E2E runs:** every Playwright command after a `.feature` edit starts with `npx bddgen -c playwright.bdd.config.ts && ` (the order of the `test:bdd` script).
- **Traceability:** every new or changed test, step file and feature carries `show-clock-change-note-on-location-cards`:
  - `@show-clock-change-note-on-location-cards @FR-X` tags above scenarios, and `// @show-clock-change-note-on-location-cards @FR-X` before each `f.Scenario`;
  - `// Verifies FR-X of show-clock-change-note-on-location-cards` (or `NFR-X`, `UX-X`) above E2E steps and in Vitest files;
  - `Implements FR-X of show-clock-change-note-on-location-cards (Dn)` in the JSDoc of new or changed production code.
- **Glossary:** use clock change, clock change window, clock change note, row note, wall-time hint, reference day, reference zone, date bar. Never "hint" for the clock change note, never "DST switch", "summer time", "winter time" or "time shift".
- **Time:** tests pin "now" with `fakeClock` from `@/lib/temporal`; never `vi.setSystemTime()` or `vi.useFakeTimers()`.
- **File size:** every file stays under 200 lines; a steps file that would pass it gets a helper next to it.
