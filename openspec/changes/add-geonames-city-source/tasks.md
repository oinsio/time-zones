# Tasks

Paths are relative to `packages/client/` unless they start with `docs/`, `.github/` or `README`. Run tests strictly one command at a time and never in the background (`CLAUDE.md`). Every new or touched production file gets a JSDoc line `Implements <ids> of add-geonames-city-source (D<n>).`, every touched test file a `// Verifies <ids> of add-geonames-city-source.` comment, and every new or changed Gherkin scenario the tags `@add-geonames-city-source @<id>` (keep the tags it already has). Use the glossary terms: city data, GeoNames source, zone city, city record, namesake, region, population. Keep every file under 200 lines; split by concern when a file would grow past it.
