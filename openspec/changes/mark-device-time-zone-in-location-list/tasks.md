# Tasks

All source paths are under `packages/client/src/`; commands run from `packages/client/` unless they start with `pnpm --filter`. Run tests one command at a time. Mutation runs: at most 5 files per run, report in `reports/mutation/mutation-report.json`. Time and the device zone in tests come only from `fakeClock(instant, timeZone)` of `@/lib/temporal` (or the pinned default of task 1.3) — never `vi.setSystemTime()` or `vi.useFakeTimers()`. Every new test, step file and feature carries `mark-device-time-zone-in-location-list` traceability (`@mark-device-time-zone-in-location-list @FR-X` tags above scenarios, `// @mark-device-time-zone-in-location-list @FR-X` before `f.Scenario`, `// Verifies NFR-X of mark-device-time-zone-in-location-list` in E2E steps, `Implements FR-X of mark-device-time-zone-in-location-list` in JSDoc of new or changed production code).
