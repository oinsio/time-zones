# Tasks

Paths are relative to `packages/client/` unless they start with `docs/` or `openspec/`.

Run tests strictly one command at a time (`CLAUDE.md`). Traceability marks:
- every new or touched production file gets a JSDoc line `Implements <ids> of move-meeting-range-and-extend-past-midnight (D<n>).`;
- every new or touched test file gets the comment `// Verifies <ids> of move-meeting-range-and-extend-past-midnight.`;
- every new or changed Gherkin scenario gets the tags `@move-meeting-range-and-extend-past-midnight @<id>`.

Sample data (the sample of `meeting-range`): current time `2026-03-08T07:30:00Z`, device time zone `Asia/Almaty`, home Almaty; locations Almaty, Moscow, Kolkata, New York. The sample meeting is 09:00–11:00 Almaty; the past-midnight sample is 23:00 on 2026-03-08 to 02:00 on 2026-03-09 Almaty (`2026-03-08T18:00:00Z`–`21:00:00Z`).

Files stay under 200 lines where possible, 300 at most. Each task is at most two hours. Groups 1–5 build the range past midnight, group 6 the sticky meeting bar, groups 7–8 the move; each group leaves the app working.
