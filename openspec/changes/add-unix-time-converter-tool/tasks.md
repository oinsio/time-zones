# Tasks

Paths are relative to `packages/client/` unless they start with `docs/` or `openspec/`.

Run tests strictly one command at a time (`CLAUDE.md`). Never run the full Stryker suite; scoped runs take at most 5 files. Traceability marks:
- every new or touched production file gets a JSDoc line `Implements <ids> of add-unix-time-converter-tool (D<n>).`;
- every new or touched test file gets the comment `// Verifies <ids> of add-unix-time-converter-tool.`;
- every new or changed Gherkin scenario gets the tags `@add-unix-time-converter-tool @<id>`.

Sample data (the sample of `unix-time-converter`): current time `2026-11-23T11:23:07Z` = Unix time `1795432987`; device time zone `Asia/Almaty`, home Almaty; locations Almaty, Moscow, Kolkata, New York (16:23:07, 14:23:07, 16:53:07, 06:23:07).

Files stay under 200 lines where possible, 300 at most. Each task is at most two hours. Locale keys are two-level (`tools.*`, `unixTime.*`, `.claude/rules/i18n.md`).
