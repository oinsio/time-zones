# Tasks

Paths are relative to `packages/client/` unless they start with `docs/`, `openspec/`, `README`, `CLAUDE.md` or `temporary-docs/`.

Run tests strictly one command at a time (`CLAUDE.md`). Never run the full Stryker suite; scoped runs take at most 5 files. Traceability marks:
- every new or touched production file gets a JSDoc line `Implements <ids> of add-unix-time-converter-tool (D<n>).`;
- every new or touched test file gets the comment `// Verifies <ids> of add-unix-time-converter-tool.`;
- every new or changed Gherkin scenario gets the tags `@add-unix-time-converter-tool @<id>` on one tag line.

Sample data (the sample of `unix-time-converter`): current time `2026-11-23T11:23:07Z` = Unix time `1795432987`; device time zone `Asia/Almaty`, home Almaty; locations Almaty, Moscow, Kolkata, New York (16:23:07, 14:23:07, 16:53:07, 06:23:07).

Files stay under 200 lines where possible, 300 at most. Each task is at most two hours. Locale keys are two-level (`tools.*`, `unixTime.*`, `.claude/rules/i18n.md`).

Placement of scenarios (`.claude/rules/bdd-unit.md`, `.claude/rules/bdd-e2e.md`): a scenario that asserts a pressed state, focus, an announcement, a keyboard path, layout, a reload, a second tab, the clipboard or the requested files goes into a `*_e2e.feature`; the rest is unit BDD. Browser runs use `npx bddgen -c playwright.bdd.config.ts`, then `npx playwright test -c playwright.bdd.config.ts --grep "<pattern>"` (the config's `webServer` builds and serves the app). The projects are `chromium`, `mobile-chrome` and the view contract projects; a scenario that needs a desktop pointer carries `@desktop-only`.

The handoff folder of this task is `temporary-docs/gnomish/github-oinsio-time-zones-164/handoff/` (from the repository root), written `$handoff` below.
