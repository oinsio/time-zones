# Glossary: Views

Interchangeable interfaces over the same model. Decisions: ADR-0002 (model, presenter, swappable views), ADR-0005 (view registry); catalog in `docs/architecture/views.md`. See [README](README.md) for the entry format.

- **View** — one interchangeable interface over the model, such as Cards or Grid. A view reads presented data and dispatches commands, and owns only its UI state (scroll, focus, open panels). *Not:* a page or a screen. *Never:* layout, mode (for the view itself), skin.
- **View registry** — the list of registered views, in display order; the settings list them and the view host shows one of them. *Code:* `views/index.ts`, `viewRegistry`, `resolveActiveView`.
- **View mode** — the user's choice of a registered view; Cards when none is chosen or the chosen view is not registered. The view never changes by itself, by width or orientation (ADR-0012). *RU:* «Вид». *Code:* `Preferences.viewMode`, `SET_VIEW_MODE`, `DEFAULT_VIEW_ID`, `resolveActiveView`, `useViewMode`, `ViewModeGroup`, `settings.viewModeLabel`. *Never:* auto, layout.
- **Cards view** — the view with one card per location, the exact time in large digits and a day track. *Code:* `CardsView`, `ViewId.CARDS`, `views.cardsTitle`. *RU:* «Карточки».
- **Grid view** — the view with hour cells aligned across all locations, for planning a meeting range. *Code:* `GridView`, `ViewId.GRID`, `views.gridTitle`. *RU:* «Сетка».
- **Cell colouring** *(planned)* — how the Grid view colours hour cells: by day period (the only option now); working hours only or none may follow as a setting. *RU:* раскраска ячеек.
- **Card** — how the Cards view shows one location row: the row header and its day track, each row a panel of its own. *Code:* `LocationRowVariant.CARD`. *Not:* a location, a grid row.
- **Grid row** — how the Grid view shows one location row: the row header, then its hour strip, then its row notes; all grid rows sit in one panel with dividers. *Code:* `LocationRowVariant.GRID_ROW`. *Not:* a card.
- **Row header** — the shared block with the drag handle, the home or Here mark, the city, the offset difference, the zone line, the local time and date with the wall-time input, and the location menu; a card and a grid row both show it. *Code:* `ZoneRowContent` without its day track, `DragHandle`, `LocationMenu`, composed by the view component `LocationRow` (`views/shared/LocationRow.tsx`). *Not:* the presented location row (the presenter type `LocationRow`).
- **Shared block** — a building block every view reuses, implemented once in `views/shared/`: the date bar, the day track, the Here mark icon, the home mark icon, the location menu, the search, the view location list (`ViewLocationList`): the location list with its empty state, load error, announcements and focus rules, and the hour grid slots (`HourGridSlots`) through which a view hands its strips and frame to it. *Never:* common component (for these blocks).
- **View contract** — the BDD E2E scenarios every registered view must pass: select a time, select a date, return to now, add and remove a location, the Here mark, and all UI states. A scenario a view cannot pass yet is excluded for that view only by a pending tag; today no scenario is excluded for any view. *Code:* `@view-contract` features.
