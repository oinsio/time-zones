# Glossary: Locations

The user's list of places and how each place is shown. Decisions: ADR-0004 (local persistence), ADR-0007 (the Here mark), ADR-0010 (the device time location). See [README](README.md) for the entry format.

- **World clock state** — the whole model state: the location list, the reference moment, the device time zone and the home location. *Code:* `WorldClockState`. *Not:* the location list alone. *Never:* `LocationsState`, app state, store state.
- **Location** — one place in the user's list: of two kinds, a city location or the device time location; a time zone ID, a city label and a country code. Its identity is the zone plus the label, so two Moscows in the same zone are one location. *Code:* `Location`. *RU:* место. *Never:* city (a location may be a zone without a city), clock, card (a card is how the Cards view shows a location), «локация» in the interface.
- **Location ID** — the stable identifier of a location, built from its time zone ID and city label. *Code:* `buildLocationId`.
- **City label** — the city name a location is shown with, in the nominative case. Stored as the user added it; a row shows the name of its zone's city record in the interface language when the stored label is one of that record's names, otherwise the stored label. *Code:* `label` (stored), `cityLabel` (row), `CitySearch.getCityLabel`, `isCityNameOfRecord`, `useCityLabels`. *Never:* title, name (ambiguous with the country name).
- **Country code** — the ISO 3166-1 alpha-2 code of a location's country (`KZ`). The country name is derived from it per [interface language](settings.md). *Code:* `countryCode`, `presentCountryName`.
- **Location list** — the user's ordered locations. Its order is the display order, and the user changes it only by reordering. It is the only stored part of the world clock state (ADR-0004, schema version 3, the first-launch list); the home location is stored with it. *Code:* `locations`. *RU:* список. *Never:* favourites, saved cities.
- **Unreadable stored list** — a stored location list that cannot be parsed or holds an invalid entry. The app shows the load error with Reset and never overwrites the stored value by itself. *Code:* `LocationsLoadStatus.UNREADABLE`. *Not:* a stored home that points to a missing location (it is cleared silently on load).
- **Location row** — the presented, view-agnostic data of one location at the effective instant: city label, country name, UTC offset, local time and date, day track, marks. *Code:* `LocationRow`, `presentLocationRows`, `presentZoneMoment`. *Not:* a card or a grid row, which are view elements built from it.
- **Here mark** — the mark on a location whose time zone ID equals the device time zone: "You are here". *Code:* `LocationMarkKind.HERE`. *RU:* «Вы здесь», подпись «здесь». *Not:* the device time location. *Never:* current location, my location.
- **Home mark** — the house icon on the home location, in the leading-mark slot; it wins over the Here mark. *Code:* `LocationMarkKind.HOME`. *RU:* «Домашнее место». *Never:* home badge.
- **Location menu** — the «⋯» menu of a row with the home action and «Удалить»; it opens on click. *Code:* `LocationMenu`. *RU:* меню места. *Never:* context menu, kebab.
- **Device time location** — the location kind that shows the device time zone. It is stored as a kind without a zone, can be removed, reordered and made home, and is offered in the search while it is not listed. *Code:* `LocationKind.DEVICE_TIME`, `DEVICE_TIME_LOCATION_ID`, `ADD_DEVICE_TIME_LOCATION`. *RU:* «Время устройства». *Never:* default location, auto-added location, Here entry.
- **First-launch list** — the list a new user starts with: the device time location alone. After that the stored list is the truth, also when it is empty. *Code:* `buildFirstLaunchLocations`.
- **Reorder** — moving a location to another position in the location list, by dragging its drag handle or by the keyboard. *Code:* `MOVE_LOCATION`. *RU:* переместить. *Never:* sort (the list has no sort key).
- **Drag handle** — the only element of a card that starts a drag reorder. *Code:* `DragHandle`. *Not:* the day track's handle.
