# Settings

The user's preferences and the page that changes them. Stored by their own repository (`src/preferences/`). See [README](README.md) for the entry format.

- **Settings page** — the page with the Gnomish Factory credit, the theme preference, the hour format, the view, the zone label, the interface language, the deploy time and the zone rules release line. *Code:* `SettingsPage`, `AppPage.SETTINGS`. *RU:* «Настройки».
- **Settings button** — the header button that opens the settings page. *Code:* `SettingsButton`. *RU:* «Настройки».
- **Preferences** — the user's choices kept on the device, apart from the location list: the theme preference, the hour format, the view mode, the zone label and the interface language. *Code:* `Preferences`, `src/preferences/`, `PreferencesRepository`.
- **Theme preference** — light, dark or system. System follows the system color scheme. Shown as icons only, in the order System, Light, Dark (`THEME_PREFERENCE_ORDER`). *Code:* `ThemePreference`, `THEME_PREFERENCE_ORDER`. *RU:* «Тема»: «Системная», «Светлая», «Тёмная».
- **Hour format** — how times of day are written, 12-hour or 24-hour; shown by the pictograms `12` and `24` (`HOUR_FORMAT_PICTOGRAMS`). *Code:* `HourFormat`, `HOUR_FORMAT_PICTOGRAMS`. *RU:* «Формат времени»: «12 часов», «24 часа».
- **Zone label** — the preference that decides which zone parts the zone line shows, the country, the zone abbreviation and the UTC offset, each on or off, all on by default; it does not affect the search. *RU:* «Обозначение часового пояса»: «Страна», «Аббревиатура», «Смещение UTC»; English interface: "Timezone label", "Country", "Abbreviation", "UTC offset"; with every part off the example reads «Только город» / "City only"; the toggles follow the order of the zone line (`ZONE_LABEL_PART_ORDER`). *Code:* `Preferences.zoneLabelParts`, `ZONE_LABEL_PART_ORDER`, `ZoneLabelPart`, `SET_ZONE_LABEL_PART`, `useZoneLabelParts`, `ZoneLabelGroup`, `settings.zoneLabelLabel`, `settings.zoneLabelCountry`, `settings.zoneLabelExampleCityOnly`.
- **Deploy time** — the instant the running build of the app was made, fixed into the build, shown on the settings page after the language group, followed by the zone rules release line; a stand-in for a version number. *RU:* «Развёрнуто …». *Code:* `APP_DEPLOY_INSTANT`, `resolveDeployInstant`, `formatDeployTime`, `useDeployTime`, `DeployTime`, `settings.deployTime`. *Not:* a version number. *Never:* build number, release date.
- **Zone rules release line** — the plain text after the deploy time that names the active release. *RU:* «Правила часовых поясов: …». *Code:* `ZoneRulesReleaseLine`, `settings.zoneRulesRelease`, `presentZoneRulesRelease`.
- **Toggle group** — a compact settings group in one row: a caption and independent toggle buttons, each on or off; it shares its row layout with the option group (`SETTINGS_GROUP_ROW_CLASS_NAME`). *RU:* группа переключателей. *Code:* `SettingsToggleGroup`.
- **Option group** — a compact settings group in one row: a caption and mutually exclusive options, exactly one checked, joined in one control; each option is shown by an icon or a pictogram, or by its name when it has neither (the view group shows the view names), and its name is its accessible name and pointer hint. *RU:* группа выбора. *Code:* `SettingsOptionGroup`, `SettingsOption`, `SETTINGS_GROUP_ROW_CLASS_NAME`.
- **Gnomish Factory** — the tool the app is built with; its landing page is linked from the settings page. A brand name: written `Gnomish Factory` in every interface language, never translated. *Code:* `GNOMISH_FACTORY_LANDING_URL`. *RU:* «Gnomish Factory».
- **Gnomish Factory credit** — the line of the settings page above the theme preference, one link "Built with Gnomish Factory" to the factory's landing page, opened in a new tab. *Code:* `GnomishFactoryCredit`, `settings.gnomishFactoryCredit`. *RU:* «Создано с помощью Gnomish Factory».
- **Interface language** — the language of every interface text, date, country name, city name of search results and city label of a city location. It is chosen in the language group of the settings page, or, when none is chosen, it follows the browser language and then falls back to English. *Code:* `Preferences.interfaceLanguage`, `SET_INTERFACE_LANGUAGE`, `resolveInterfaceLanguage`, `useInterfaceLanguage`, `useActiveInterfaceLanguage`, `InterfaceLanguageGroup`, `settings.languageLabel`. *RU:* «Язык интерфейса»; the group caption is «Язык».
- **Locale metadata** — the `_meta` block of a locale file: `code` (equal to the file name, a canonical language tag), `name` (English name, the sort key), `nativeName`, `baseLanguage`, `emoji`. It is never a translation. *Code:* `LocaleMetadata`, `parseLocaleMetadata`.
- **Locale registry** — every locale file whose locale metadata is complete and valid, collected automatically and sorted by `name`. It is the only source of the supported languages, the i18next resources and the settings list. City data is kept for `CITY_NAME_LANGUAGES` only. *Code:* `localeRegistry`, `buildLocaleRegistry`, `RegisteredLocale`, `SUPPORTED_LANGUAGES`.
- **Dialect** — a locale whose `baseLanguage` differs from its `code`; easter-egg languages are dialects. A missing text or language-keyed value comes from the base language, then English. Dates, weekdays, months and country names formatted through `Intl` use the same order as their locale list. *Code:* `resolveLanguageFallbacks`, `pickByLanguageFallback`.
